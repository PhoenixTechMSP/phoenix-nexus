# Brand kit

| File | Size | Use |
|---|---|---|
| `banner-dark.png` | 1280x640 | README on dark theme, docs |
| `banner-light.png` | 1280x640 | README on light theme, docs |
| `social-preview.png` | 1280x640 | GitHub: Settings > General > Social preview (upload it there) |
| `phoenix-icon-512.png` | 512x512, transparent | Organisation avatar, documentation favicon |

The in-app images (header, login, loading screen, favicon in `client/public/`) are generated from `scripts/brand/phoenix-mascot-source.png` by `python3 scripts/brand/make-assets.py`. Each PNG stays under 30 KB, and the dark-theme variant lightens the slate hub of the mascot.
